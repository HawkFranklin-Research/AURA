# AURA / Nimbo — Play Review Access

## App Access

```text
No login required.

AURA / Nimbo needs no account or sign-in. Reviewers can use every feature
immediately after installing the app and downloading a model from the in-app list.
```

## Suggested reviewer instructions for Google Play

```text
1. Install and open the app.
2. Accept the short welcome/privacy note.
3. On the home screen, tap "Download starter model" (or pick any recommended model)
   and wait for the download to finish. A foreground notification shows progress.
4. Open Chat and send a prompt - the model responds fully on-device.
5. (Optional) Open "Look" to ask about a photo with a vision-capable model.
6. (Optional) Open "Labs" to test single prompts and settings.

All processing happens on the device after the model is downloaded. No internet is
required for chat once a model is present.
```

## Notes

```text
- A working internet connection is needed once, to download a model.
- 8GB+ RAM device recommended for smooth performance.
```
