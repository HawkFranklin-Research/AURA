# Privacy policy deployment for optional OpenRouter chat

Public URL: https://hawkfranklin.eu/products/aura-privacy.html

The Markdown policy in this folder and root `PRIVACY_POLICY.md` are synchronized.
The live website is maintained outside this repository and has NOT been updated
by these code changes. Publish equivalent policy text there before an online-chat
release, then verify the public page. Also publish the callback page and Digital
Asset Links file described in `docs/openrouter-integration.md`.

Do not retain old global claims of "no cloud inference", "internet only for model
downloads", or "all microphone processing is guaranteed offline". Local and
online modes have different data flows. Firebase Analytics collection is explicitly
deactivated in this update's Android manifest; validate the merged release manifest.
